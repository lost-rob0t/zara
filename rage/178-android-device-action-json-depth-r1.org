* Research
- =ZaraDeviceActionCodec.decodeServerMessage= has a 64 KiB envelope bound and a closed typed device action schema.
- Its private recursive =DeviceJsonParser= has no container nesting bound.
- Android text/capability decoders use a 64-container JSON policy; typed side-effect requests should not retain an unbounded recursive parser.

* Design / adversarial review
- Apply one 64-container bound across objects and arrays; root object consumes one level.
- Preserve typed capability/action validation, correlation, replay semantics, and all byte limits.
- Do not alter Core's open replay-horizon contract (#492) or Core-owned transaction.
