** Architecture / Design
- Completed in =rage/880-882-voice-pipeline-design.org=.
- #880: =PulseOutputStream= (pacat) mirrors the parec capture path;
  bounded open on a one-shot executor; failed opens degrade the turn and
  drop chunks instead of queueing into a dead stream; daemon =_send=
  failures name message/stream/turn.
- #881: two wall-clock bounds during recording (frame-inactivity
  =capture_stall_timeout= + utterance cap) so the loop can never park;
  =PulseInputStream= watchdog fails loud on a silent parec.
- #882: =[stt] beam_size= plumbed to =make_faster_whisper_transcriber=;
  measurement harness =scripts/stt-phrase-benchmark.py=; default model
  unchanged without measurement support.

** Adversarial review
- Open-adoption race: a done-callback closing a stream the main thread was
  about to adopt was eliminated by moving adoption inside the pool task
  under a generation counter; a timed-out open bumps the generation so the
  late stream self-closes.
- Watchdog false positives are impossible for a healthy parec: it streams
  silence frames continuously, so bytes flow even in silence; the watchdog
  only fires on true starvation.
- First-failure-wins for =last_error= so the stall reason is not masked by
  the subsequent EOF report from the terminated process.
- Secrets: transport warnings keep route bytes and message ids out of logs
  (existing #575 assertions still green); only type/stream_id/turn_id are
  added.
- The stall deadline and utterance deadline can expire in the same tick;
  the expiry branch reports the binding (smaller) deadline to keep the
  status honest.
