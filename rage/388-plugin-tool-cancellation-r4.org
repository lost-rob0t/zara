* Selected bounded architecture
- Preserve current-master =graph.py= byte-for-byte except the cancellation import, one exact ToolNode invocation helper, and replacement of the one direct =tool_node.ainvoke= call.

- The read-only token is carried in the explicit LangChain =RunnableConfig.configurable= map for executor crossings; a ContextVar remains a direct-call fallback.
- On outer =CancelledError=, Core signals the token before cancelling/awaiting the ToolNode task, then the existing =ToolCancelled(reason="turn cancelled")= event remains the sole terminal authority.
- Approval rejection and unavailable-tool paths never enter the cancellation scope.
- Plugins receive only =ToolCancellation.cancelled/wait= through the public plugin API; no model-visible argument, arbitrary process control, new runtime, or second approval path exists.

* Adversarial invariants
- concurrent invocations cannot signal each other;
- sync and async tools see the same Core-owned signal;
- cancellation is signalled before cooperative cleanup observes task cancellation;
- plugin code cannot set, replace or retarget the signal;
- existing tool event ordering and failure semantics remain unchanged outside cancellation;
- exact-head full tests, Nix flake/package, Android compatibility and both mic lanes remain mandatory before merge.
