* Architecture / design
- One =S1MiniTranscriptNormalizer= implementing the existing #216 provider shape; no coordinator/runtime changes.
- Endpoint is explicit and required. The adapter sends to exactly that configured endpoint and has no fallback endpoint, provider discovery, model download, or cloud path.
- Model identity remains configurable, defaulting to =superwhisper/s1-mini=; version metadata defaults to =v1=.
- Prompt/control construction is Core-owned from validated enum-like configuration. Transcript text is only user-message payload and cannot alter system/control fields.
- Use =httpx.AsyncClient=; tests inject =httpx.MockTransport= so default CI has no network/model dependency.
- Map connection/HTTP model absence to =unavailable=; HTTP timeout to =timeout=; unsupported language, malformed/empty/reasoning/wrapper/oversized/pathologically-expanded output to typed #216 statuses.
- Do not catch caller =CancelledError= inside the HTTP adapter: canonical task/turn cancellation must remain authoritative. #216 stale-turn fencing supplies typed cancelled results where results are still representable.
- Reject explicit =<think>=/reasoning payloads and obvious response wrappers instead of allowing an explanation/summary to become user text.
- Enforce absolute output bound plus configurable expansion ratio; numeric timeout/ratio configuration must be finite and positive so NaN/Infinity cannot escape validation or explode during bound calculation.
