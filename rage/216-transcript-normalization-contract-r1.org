* Architecture
- One post-STT provider-neutral service; this slice does not create a second voice coordinator or STT path.
- =IdentityTranscriptNormalizer= is the canonical =off= backend and performs no text transformation.
- Providers are selected through a bounded registry rather than coordinator =if/elif= growth.
- The normalizer receives only final transcript text plus language/turn/trace correlation. It receives no tools, RuntimeHost, plugin registry or execution authority.
- Provider output is re-projected into Core-owned typed status/model/version fields and bounded before use.
- A caller-supplied current-turn predicate fences stale work before and after provider execution.
- Failure fallback is explicit above the provider via =select_normalized_text=; providers cannot silently choose raw fallback or increase authority.
- No transcript body is logged or persisted by this module.

* Adversarial review
- oversized input never enters a provider;
- empty/non-text/oversized provider output is invalid;
- unknown backend is typed unavailable;
- provider timeout is typed and bounded;
- a turn made stale during provider work cannot return usable normalized text;
- unsupported language remains an explicit status rather than an implicit rewrite;
- provider-supplied backend/model metadata cannot replace the registry-owned provider identity;
- normalizer output remains untrusted user text and has no action authority.
