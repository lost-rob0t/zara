** Recovered-source findings and bounded design
- Existing ContextManager mutates history once per compression/truncation step.
  A later failed summary or impossible budget can therefore leave a partially
  destroyed prefix. Stage all destructive changes locally and publish once only
  after full success plus active generation/revision checks.
- Existing message counter ignores tool-call arguments. Count complete serialized
  provider-visible message payloads (including tool calls), with a conservative
  local fallback and injectable provider/token counter. Do not label an estimate
  a measured provider-token count. No tokenizer dependency or model change.
- LangChain primary reference: https://reference.langchain.com/python/langchain-core/messages/utils/trim_messages
  documents preserving a leading system message, a valid human-start history,
  and matching tool-result ordering. Generic message slicing cannot provide our
  complete-turn transactions or stale generation semantics; retain recovered
  complete Human/assistant/tool turn grouping and current validation helpers.
- First recovery slice: existing context/skill modules, shipped skill packaging,
  current AgentManager integration through the existing #260 advice registry,
  explicit manual compact API/audit and metadata-only browser projection. Keep
  current memory-provider deferral and canonical backend memory persistence.
- Supplied task history uses an isolated ephemeral ContextManager; it cannot
  replace interactive context or persist its transient task system context.
- Context remains active inference state; durable raw conversations and derived
  memory remain owned by existing stores. No alternate scheduler or database.
- ConversationManager exposes a compatibility history projection backed by the
  context owner; all production mutations route through ContextManager.
- Typed attachment lifetime/principal reconciliation and Android/desktop UI
  projection stay explicit remaining #51 work before extending #654. Recover
  existing advice toggles now; do not import the old process-global unscoped
  attachment store or treat attachment context as task identity.
- Rejected: blindly merge all old agent orchestration (loses backend/hook/task
  and provider changes); new hook engine; new tokenization dependency; browser
  entries containing instruction bodies; replacing existing packaging wholesale.
