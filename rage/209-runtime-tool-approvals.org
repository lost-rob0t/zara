** Analyze / Research
- Completed in =rage/209-runtime-tool-approvals-research.org=.
- The installed LangGraph API was exercised in the Nix shell: checkpointed =ainvoke= returned =__interrupt__= and resumed with =Command(resume=...)= under a stable thread id.
- Research rejected a plain Future-only gate, a second executor, a broad migration to middleware, and unsafe cross-process resume of generic non-idempotent tools.
- Selected restart policy :: live asynchronous approval is resumable; timeout, cancellation, restart and shutdown fail closed and erase the process-local checkpoint.

** Architecture / Design
- Completed in =rage/209-runtime-tool-approvals-design.org=.
- One principal-owned controller coordinates RuntimeHost decisions with a pure LangGraph interrupt node; a separate gated node delegates approved calls to the existing =ToolNode=.
- Server configuration is approval-policy authority. Approval envelopes and events never include tool arguments, results or user-provided rejection text.

** Adversarial review
- Completed. The design now gathers every approval before any side effect, atomically consumes pending ids, preserves original tool-result ordering, revalidates tool bindings, and defines the exact cancellation/start boundary.
