- Retain typed attachment kinds/scopes/sensitivity and opaque references from

- Small slice: explicit text acquisition only, through an injected store bound
  to one canonical PrincipalContext. No upload/CLI/UI command, filesystem reads,
  locators, binary decoding, persistence, provider/runtime, or permission path.
  Caller supplies an already-authorized text snapshot; a string path is data.
- Scope: TURN requires conversation and exact turn; CONVERSATION requires exact
  conversation. Persistent scope deferred; all entries have bounded monotonic
  TTL. Store count, aggregate UTF8 bytes, per-item bytes and render bounds are
  finite. Failed acquisitions/renders are atomic. Opaque missing, expired,
  revoked and wrong-scope references fail with the same payload-free error.
- Inject store only into LangGraphRuntimeBackend; verify manager principal
  identity before resolution. Existing nonempty-ID rejection remains when no
  store is configured. Render as labelled untrusted transient model input;
  it cannot register tools or approve actions. Do not use extra_system_context
  because that signals isolated task execution and changes persistence policy.
- Backend finally releases TURN entries on success/error/cancel/deterministic
  routing. CONVERSATION entries expire or revoke explicitly; stop clears all.
  Keep existing _persist_turn owner and raw transcript behavior unchanged.
- Tests before production: principal/conversation/turn isolation, guessed and
  duplicate IDs, expiry/revocation, quota recovery, malformed values, secret
  withholding and diagnostics privacy; backend success/failure/cancel cleanup,
  transient history, ordinary persistence and task isolation, restart cleanup.
- Required gate: focused RED/GREEN, context and adjacent runtime suites,
  nix develop -c bash scripts/test-all.sh; nix flake check; nix build;
  independent exact-head review and full existing CI. No device acceptance.
