* Design
- Manual capture is bound to the exact authenticated connection generation and session id that authorized it.
- Disconnect/reconnect, generation replacement, or authenticated session replacement cancels physical recording exactly once through the existing PushToTalkController owner.
- Canonical runtime publication invalidates stale capture before any external UI observer sees the new state.
- Permission revocation and host-stop continue through the same cancellation owner.
- No second runtime/capture state machine.

* Gate
- Coordinator tests cover connection loss, replacement generation/session, duplicate invalidation, permission revocation, host stop, and normal commit.
- Wiring contract requires stale-capture invalidation before UI state publication.
- Exact-current-head Android/full-Nix/package/shared-mic CI is required before promotion.
