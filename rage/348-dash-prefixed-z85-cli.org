* Architecture / adversarial decision
- Preserve one existing =zara-server= management parser and the current security state/admin implementation.
- Do not globally reinterpret unknown dash-prefixed tokens as values.
- Configure only =--security-enroll-key= as an exact one-token argument; a tiny scalar action preserves the existing string-valued Namespace contract while allowing argparse to consume a leading-dash token.
- Run that consumed token through Zara's canonical CURVE public-key normalizer during parsing. Invalid length/alphabet remains malformed CLI input, and unrelated unknown options retain argparse fail-closed behavior.
- No new key format, enrollment path, protocol message, or Android-specific parser.
