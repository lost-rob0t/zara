#+title: RAGE #309 design — Prolog config recovery

* Boundary
One configuration-authority cleanup. Preserve normal SWI-Prolog, normal LLM provider configuration, existing semantic/device split, and #5's base/local layering. No new provider/runtime/command system.

* Design
1. =kb_config:search_engine/1= built-in fallback becomes ="https://search.brave.com/search?q=~w"=.
2. Remove =prolog_rlm_enabled/1= and =prolog_rlm_model/1= from =kb_config= exports, dynamics, and defaults.
3. Remove =prolog_rlm_*= validation clauses from both user and server config loaders. Old declarations therefore hit the existing unsupported-fact domain error.
4. Remove Prolog-RLM examples from generated =config.pl=. Replace that space with explicit ownership text: =config.pl= is compatible/provisionable base; =config.local.pl= is mutable/private and is never generated by Zara.
5. Update installation/config documentation to the same ownership contract and remove the obsolete direct-mode/live-smoke instructions.
6. Preserve =config.local.pl= ordering and server/device validation unchanged.

* Rejected alternatives
- Keep dormant RLM predicates but mark deprecated: rejected because Zara's permanent policy says do not revive the runtime/backend/dependency, and accepting a no-op configuration knob creates false authority.
- Auto-write Brave into =config.local.pl=: rejected because it would violate mutable/private ownership and manufacture user state.
- Add a search-provider registry in this slice: rejected as needless architecture; current =search_engine/1= data template already supports the requested default and overrides.

* Acceptance-to-test map
- Fresh default is Brave Search :: assert =kb_config:search_engine("https://search.brave.com/search?q=~w")= before user overrides.
- Local search remains user authority :: retain/strengthen existing base + local override test and assert base is unchanged.
- RLM knobs absent :: assert no =kb_config:prolog_rlm_enabled/1= or =kb_config:prolog_rlm_model/1= current predicates.
- Stale RLM facts fail closed :: table-drive each declaration through =reload_user_config/0= and require =domain_error(zarathushtra_user_config_fact,...)=.
- Generated base config is clean and teaches ownership :: generate it in isolated XDG, assert no =prolog_rlm_= substring and assert =config.local.pl= ownership text.
