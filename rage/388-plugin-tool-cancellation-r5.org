* Selected architecture

- The wrapper creates one private =threading.Event= and public read-only =ToolCancellation= view per exact invocation.
- The wrapper binds that view in a ContextVar, launches the canonical ToolNode =execute(request)= coroutine as a child task, and shields it.
- On outer cancellation, the wrapper sets the event before cancelling/awaiting the child task, so cooperative sync cleanup and async =CancelledError= handlers can observe cancellation first.
- =gated_tools_node= retains existing approval, availability, event publication, result normalization, and terminal =ToolCancelled(reason="turn cancelled")= authority.
