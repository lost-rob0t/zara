* Objective
Land the first Android-owned manual push-to-talk slice on the canonical authenticated ZARA/1 client without adding a second assistant, recorder, transport, STT, TTS, or runtime.

* Ownership and dependencies
- Android owns microphone permission, =AudioRecord= capture, framing, UI controls, and client-side lifecycle.
- The Zara daemon remains authoritative for STT, assistant routing, tools, LLM, memory, and TTS.
- This transaction is based on canonical first-usable Android master after #173 authenticated client and #197 Compose shell landed.
- No Core production file is changed by this PR.

* Invariants
1. There is exactly one Android microphone owner.
2. Voice commands use the same authenticated CURVE DEALER, Zara session, and single-thread client actor as Chat.
3. Permission denial, disconnected state, stale session/stream, malformed acknowledgement, remote protocol error, and recorder failure fail closed.
4. Local capture state cannot advance to Capturing until the server has acknowledged =audio.input.start=.
5. Every =audio.input.chunk= is exact mono PCM16 16 kHz, 512 samples / 1024 bytes, copied before transport ownership transfer.
6. Commit/cancel are terminal and recorder ownership is released before the terminal server command.
7. No transcript, playback, or success state is fabricated before canonical server events exist.
