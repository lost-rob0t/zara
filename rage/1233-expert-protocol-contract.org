** Design / proposed decision
Start with the shared descriptor and invocation schemas, a declarative operation/lifecycle vocabulary, and a pure Prolog validator for normalized invocation data. Schemas and Prolog must agree on protocol identity, integer limits and inert values. Keep validation distinct from authorization and execution. Preserve every existing Prolog source; new files are additive.

An adapter must still check authenticated identity, current activation, schema-specific domain input, deadline/resource budgets and permission immediately before actual dispatch. Passing the structural contract is not an activation receipt or capability grant.
