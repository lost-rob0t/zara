* Research
- The Android app now packages the canonical resolver sources and exposes =resolve_frames/4= through the Trealla entrypoint, but =SemanticFixtureRunner= still accepts abstract =SemanticRuntime= implementations and therefore cannot by itself prove SWI-versus-Trealla execution.
- The fixture seed at =android/app/src/main/assets/prolog/portable/semantic_fixtures.json= already carries utterance/state/expected terms and is the correct single corpus input for this gate; do not create a second Android-only semantic corpus.
- Android pins Trealla source revision =b25ccfb8e485a697bb47f1947d6fb8e0ad4e6aaf= in =android/flake.nix=. The parity gate must execute that exact engine source, not a host package with unrelated version drift.
- SWI remains the server reference runtime. Both runtimes must consult the same canonical resolver dependency set and serialize terms canonically before comparison.
- Host execution of the exact pinned Trealla engine is acceptable as the deterministic CI execution surface for the shared Prolog engine semantics; JNI/ABI/APK packaging is already covered separately by the Android native gate. This gate does not claim hardware/lifecycle parity, which remains #178/#179.
- Trealla's pinned CLI supports ordered file consultation and =-g/--goal= evaluation; its GNUmakefile has a deterministic native =tpl= target. The build uses a writable copy of the Nix-pinned source because the Nix store source is immutable.

* Architecture / design
- Add a non-interactive Android-owned parity command under =scripts/= and invoke it from =scripts/test-android.sh= after the pinned Trealla source is available.
- Build a host Trealla executable from the exact =ZARA_TREALLA_SOURCE_DIR= revision inside the Android dev shell, with no network fetch.
- Execute every fixture through SWI and pinned Trealla using the same staged canonical files: =semantic_core.pl=, =modules/intent_frames.pl=, =modules/normalizer.pl=, and =kb/intents.pl=.
- Query =resolve_frames(Utterance, State, [], Frames)=, normalize through =normalize_frames/2=, and serialize the list with =write_canonical/1= on both engines.
- Compare SWI output against Trealla output and independently against the fixture's expected frame list. Identical shared regressions therefore cannot false-green.
- Empty result, consult failure, parse failure, missing runtime, malformed fixture, runtime crash, timeout, duplicate id, invalid state, or output cardinality mismatch fails closed.
- Keep this gate Android-only. Do not modify Python runtime, daemon protocol, desktop, config, or sibling-core files.

* Adversarial review
- Do not compare against fixture =expected_terms= alone; both runtimes must execute.
- Do not let one runtime's output become the expected oracle for the other without also checking the corpus expectation.
- Pin Trealla by the existing Nix-provided source tree; no curl/git clone/HEAD fetch.
- Bound fixture count to 256, fixture ids to 96 characters, utterances to 4096 characters, and each runtime invocation to 20 seconds.
- Build Trealla with network/FFI/SSL/thread extras disabled for this semantic gate; those facilities are irrelevant to the portable resolver.
- Temporary source/build/staging state is isolated beneath =mktemp= and removed on exit.
- This gate proves shared semantic-engine parity only. Android process lifecycle, JNI resource leaks, concurrency/cancel, and device behavior remain covered by their owning Android gates/issues.
