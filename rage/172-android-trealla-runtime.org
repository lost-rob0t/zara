- The next missing boundary is deterministic Android runtime lifecycle before JNI/native binding: initialization must load the canonical portable core explicitly, evaluation must be impossible before readiness, shutdown must be idempotent, and native failures must remain failures rather than fabricated semantic output.

* Design / adversarial review
- Introduce a narrow =TreallaBridge= interface that represents the future JNI implementation without pretending a native runtime already exists.
- =TreallaSemanticRuntime= owns lifecycle state and implements the existing =SemanticRuntime= contract.
- Initialization takes an explicit portable core asset path; no implicit discovery or fallback.
- Failed initialization leaves the runtime unready so callers may surface failure/retry explicitly.
- Evaluation is legal only while ready and wraps bridge solutions in the frozen =ZARA-SEMANTIC/1= contract.
- Close is idempotent and never invokes native shutdown more than once.
- No raw arbitrary goal surface is added beyond the already-bounded fixture query contract.
