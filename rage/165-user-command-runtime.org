** Initial research
- #165 requires parameterized commands, collision policy, capability/provider revocation, and atomic hot reload while preserving principal ownership.
- Existing =UserCommandDefinition= already persists typed =CommandSlot= schemas and exact trigger/alias uniqueness per principal.
- Existing =UserCommandCompiler= already compiles slot bindings into =IntentFrame= templates, rejects protected built-in triggers, validates capability/location contracts, and publishes immutable =CompiledCommandRegistry= snapshots atomically.
- Existing tests already prove a parameterized timer frame template, built-in collision rejection, atomic failed reload, and provider removal causing the next reload to fail.
- Existing =UserCommandAuthoringService= performs compile-before-commit, rollback on publication failure, and bounded undo.
- Code search finds no production consumer of =CompiledCommandRegistry.snapshot()= outside the registry itself. The missing architectural seam is therefore runtime-safe resolution/slot completion against an immutable compiled snapshot, not another persistence/compiler implementation.

** Design direction
- Add one small resolver over an immutable registry snapshot rather than wiring commands directly into =RuntimeHost= (owned later by #160).
- Resolve exact trigger/alias first, then bounded parameterized trigger templates. Never use first-match ambiguity resolution.
- Reuse =ClarificationCoordinator= / typed slot parsing for missing values instead of a command-specific parser.
- Resolve produces typed command/frame/action-template data only; execution and approval remain outside this slice.
- Capability revocation is represented by compiling/publishing a new valid snapshot from the current capability catalog. Failed reload preserves the prior snapshot; callers must not report the new capability state as active until publication succeeds.
- Keep provider/platform implementation details out of persisted command definitions.

** Planned acceptance tests
1. =focus timer for 35 minutes= resolves a declared duration slot and returns a COMPLETE user =IntentFrame= with the existing duration validator semantics.
2. Bare =focus timer= returns MISSING(duration) and can be projected through the canonical clarification coordinator rather than a parallel dialogue parser.
3. Trigger/alias/template ambiguity returns an explicit conflict result, never first-match execution.
4. Exact protected built-in phrases remain compiler-rejected.
5. Concurrent readers holding an old immutable snapshot remain coherent while a new snapshot is published.
6. Failed reload after capability removal leaves the previous registry snapshot identity/current commands unchanged.
7. Principal isolation remains structural because each resolver is constructed over one principal-bound registry/store publication path.
