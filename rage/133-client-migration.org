- Desktop blocker :: =QtRuntimeBridge= submits through its supplied object but subscribes through the module-global in-process runtime bus, so a remote client cannot deliver its private event bus to Qt.

** Design
- Dedicated artifact :: =rage/133-client-migration-design.org=.
- One application-facing client policy/factory returns =ZaraClient=; explicit standalone uses =InProcessZaraClient= and remote uses =ZmqZaraClient=.
- Reuse existing request-id replay/reconnect rather than a second transport.
- Client disconnect/desktop exit is separate from shared-daemon shutdown.
- Authentication/pin/protocol/authorization failures fail closed and never silently fall back to a private runtime.
- No Qt-specific ZARA/1 protocol or second conversation/runtime stack.
