** Research
- Existing =AgentLoopAdviceRegistry.list_registrations()= and =AgentLoopRegistry.list_registrations()= expose callback-bearing registration objects, so they are unsafe as an operator diagnostic API.
- =AgentManager= is the canonical owner of both registries and reads =[agent].backend= for execution; it can therefore project configured backend ownership and override state without introducing another source of truth.
- Runtime diagnostics must stay on the existing =AgentManager -> LangGraphRuntimeBackend -> RuntimeHost= ownership path.
- Multiple =override= registrations already fail closed during invocation; diagnostics must mirror that by reporting conflict with no guessed winner.

** Design
- Add immutable callback-free advice metadata: registration id, kind, owner, priority, sequence.
- Add immutable callback-free backend metadata: registration id, name, owner.
- Add one immutable customization diagnostic containing hook gates, configured backend/known/owner state, safe registry snapshots, and unique override winner or conflict state.
- Delegate the same object through =LangGraphRuntimeBackend= and =RuntimeHost=; no duplicate cache or registry.
- Never include callbacks, source/config payloads, prompts, transcripts, tool data, exception text, credentials or secrets.
