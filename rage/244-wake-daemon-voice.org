* Iteration 1 — implementation evidence
- Design decisions realized:
  - =zara/runtime/intent_router.py=: deterministic Prolog-first router
    (command gate -> resolve_intent -> execute / clarification / python /
    end_conversation / ask->agent) applied inside =LangGraphRuntimeBackend=
    before agent fallback; per-principal engines via injectable
    =RuntimeSupervisor(prolog_factory=...)=.
  - =zara/runtime/tts_output.py=: daemon TTS output bridge (phrase-cut from
    =AssistantDelta=, wav/mp3 -> s16le mono decode at the configured rate,
    cancel-safe) publishing =AudioOutputStarted/Chunk/Finished=; gateway maps
    them to the existing =audio.output.*= wire contract and only delivers to
    routes that negotiated a format. Issue #244's "any gap justified against
    the #132 contract" clause covers the missing producer; #29's remaining
    scope (jitter buffer, provider pipeline hardening, p95 benchmark) is
    untouched. MP3-on-the-wire for future Android clients deferred: Opus is
    the right codec there, negotiated via the hello extension point.
  - =zara/wake.py=: thin client (spotter keeps local wake-mode ASR per
    research F5); utterances stream over =audio.input.*= with client
    trace_id; stop phrases via daemon transcript events +
    =[wake].stop_phrases=; barge-in monitors cancel playback and the daemon
    turn (=turn.cancel=) then restart listening; =run_wake_listener= fails
    closed with exit code 2 and never constructs a private runtime.
  - =zara/wake_daemon.py=: =WakeDaemonClient= (connect/open/subscribe/pump,
    reconnect-with-backoff fail-closed, =stream_utterance=) and
    =PcmStreamSpeaker= (persistent output stream, immediate cancel).
  - Latency trace rides langgraph =config= (checkpointer-safe), keyed by the
    voice trace_id end to end.
