#+title: RAGE #575 r3 — transient ROUTER backpressure

* Start
- Consumed issue: #575 — P1 stock ZARA/1 Android interop determinism.
- Immutable start commit: =461eed70d1fd0efc26d90091b5171c973cba3c69=.
- Scope: Core shared ZARA/1 transport only. No =android/**= production changes.

* Research
- The stock Android interop failure occurs after authenticated connection and manifests as a text request timeout.
- Current =ZaraZmqGateway._send= catches =zmq.Again= together with permanent =zmq.ZMQError= and drops the route for either class.
- Current =_drain_outbound= removes a queued message before attempting its nonblocking ROUTER write, so transient backpressure can discard the exact pending reply before delivery.
- The existing diagnostic test encoded the older assumption that =Again= means route death. That contract conflicts with ZeroMQ nonblocking backpressure semantics and with #575's deterministic text-turn requirement.
- Existing per-route outbound queues are already bounded by =event_queue_size=; the fix must preserve that bound rather than add retry loops or timeout inflation.

* Design
- Treat =zmq.Again= as transient send backpressure, not proof that the routing identity is gone.
- Preserve the exact pending reply and route; a later owner-loop drain retries it.
- Keep route-local FIFO ordering and exactly-once removal after a successful write.
- Keep permanent/unroutable =zmq.ZMQError= fail-closed by dropping the route.
- Keep bounded secret-safe diagnostics: log only the exception class, never route identities, protocol IDs, payloads, endpoints, or key material.
- No sleeps, retry-until-green loops, timeout increases, second runtime, or Android-specific protocol path.

* Acceptance mapping
- Transient =Again= preserves route and pending =turn.accepted=: =t/test_zmq_transient_backpressure.py=.
- Existing diagnostics are updated so =Again= remains secret-safe without requiring route destruction: =t/test_zmq_send_diagnostics.py=.
- Permanent =ZMQError= remains fail-closed and secret-safe: =t/test_zmq_send_diagnostics.py=.
- Final gate: focused tests, =scripts/test-all.sh=, =nix flake check=, package/build gates, Android stock interop/APK gate, and exact-head GitHub Actions.
