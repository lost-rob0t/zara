* Failure analysis

- =PushToTalkController= correctly cancels the active capture/server stream before invoking =onRecorderFailure=.

* Design
- Wire =PushToTalkController.onRecorderFailure= to the existing =reportVoiceStreamFailure= boundary.
- Preserve one capture owner and the existing server cancellation path.
- Reuse =VoiceDiagnosticFailure= redaction; never expose raw recorder/platform exception messages.
- Do not create a parallel recorder state machine.
