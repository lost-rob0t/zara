* Design
- Playback tied to a missing/reconnecting/replaced authenticated session is stale and must be interrupted.
- VoiceStreamSinkActor reset runs on its existing single serialized owner, closes playback, clears session ownership, and permits a fresh stream even if the server later reuses the same session id.
- Playback/session ownership is detached before any fallible close operation; a broken platform close cannot leave a stale owner addressable by later same-session or replacement-session events.
- No second playback owner or runtime state machine.
