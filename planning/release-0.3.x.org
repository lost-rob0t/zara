* Selection rules
1. Only PRs in the frozen slate merge to =release/0.3.x= without an explicit release-blocker justification.
2. Every candidate rebases/merges the frozen branch before final review.
3. Focused red/green tests precede the full repository gate.
4. Exact candidate SHA must pass required GitHub Actions. Stale green runs do not count.
5. User-visible changes update =CHANGELOG.md= in the same PR.
6. No immutable tag or release publication until the integrated candidate is approved and version context is promoted.
7. Feature expansion outside the slate stays on =master= unless it becomes a release blocker.
