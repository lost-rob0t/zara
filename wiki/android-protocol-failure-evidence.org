* Ownership and invariants
The existing =ZaraTextClientActor= executor remains the sole text socket
owner. =TextTurnProtocolTrace= is an actor-local bounded recorder, not a
second transport, reader, dispatcher, or mutable connection authority.

- Capture receive byte/frame counts before decoding, including malformed frames.
- Capture typed text metadata before session, request and expected-message checks.
- Advance from awaiting acceptance only after the existing receipt checks pass.
- Snapshot the failing request before connection-failure notification or cleanup.
- Preserve the snapshot across a later reconnect; never project it as live state.
- Keep at most 32 metadata records, a dropped-record count, and independent
  last-RX/original-submit metadata, so stream volume cannot erase the submit.
- Do not retain envelope/body objects, prompts, reply text, audio, keys, or
  ByteArray references. Bound identifiers to 128 characters and type to 64.
- A transmit record says =attempted=, not delivered or server-acknowledged.
- Suppress one matching sparse completion callback following a rich failure;
  do not suppress later known-generation attempts, different operations, or
  unrelated failures. Clearing the tracker clears this guard too.

The text includes =--- protocol failure trace ---=. JSON includes a root
=protocol_failure_trace= array of metadata maps. Trace sizes and sequences

Missing metadata is explicitly unknown/null, not invented from a new session.

* Scope limits
This slice captures session-desynchronizing failures during text submits.
It does not yet wire all live =remote.last_rx_*= / =remote.last_tx_*= fields,
hello negotiation, voice-pump failures, successful-turn telemetry, or
ordinary non-desynchronizing server rejections. Interleaved voice/device
frames retain shape but are not typed by the text-specific recorder.

Protocol ordering, accepted message types, deadlines, retry/backoff policy,
model selection and server behavior are unchanged. This does not fix or
prove the root cause of the original unexpected message. No request is
replayed automatically and a reconnect is not labeled turn success.
