* Implemented boundary

=OrgTranscriptCapture.render= validates finalized timestamped transcript spans and
exact-quote note/todo proposals, then emits ordinary Org. =OrgRepository.saveTranscriptCapture=
uses the existing configured Org repository; no server, model, permission, plugin,
database, executor or scheduler is created by ingestion. Existing =OrgParser.parse=
finds generated todos and =OrgRoam.build/search= indexes transcript/note headings.

This is an ingestion API, not an installed microphone-to-memory user flow. It does
not transcribe audio or infer commitments. A future extractor supplies proposals;
the boundary requires each proposal's exact quote and UTF-16 character range to
match one known transcript span. That proves textual provenance, not that speech
is true or that a proposed todo should be executed. Recorded instructions never
become runtime commands or external actions here. Proposal review state is explicit.

IDs are caller-supplied stable capture IDs plus span IDs and quote ranges/kinds.
Namespace separators cannot occur in input IDs. Original text and quotes are
preserved as UTF-8 Base64 properties (encoding, not encryption); display text
flattens line breaks and neutralizes Org links, timestamps and tag syntax.
Transcript/note headings cannot accidentally introduce TODO state. No generated
source blocks, Babel calls or executable links are emitted.

Limits: 30 minutes per capture, 256 ordered nonoverlapping spans, 4,096 UTF-16
code units per span, 65,536 total, 64 extracts, 300 code units per extract, and
128 capture documents under =memory/captures/=. Existing identical retries remain
allowed at capacity. The caller can review/delete files through the normal Org
workflow; ingestion never silently evicts data. There is no audio retention here.

The process-wide ingestion lock prevents concurrent ingress from this API from
duplicating writes, including separate repository adapters in the same process.
Existing content must match the complete deterministic document byte-for-byte;
changed capture payloads or user edits cause a visible conflict and no overwrite.
Write failures propagate; readback detects short writes. An uncertain partial
document remains a conflict on retry and needs explicit repair/deletion.

The existing SAF/shared provider write contract is NOT atomic create-if-absent.
Other processes and external editors do not share the ingestion lock. Do not wire
multiple independent capture workers to it until the owning provider supplies an
atomic conditional-create boundary. No cross-process exactly-once guarantee,
power-loss durability, SAF device acceptance or automatic partial-write repair
is claimed by this slice.

* Platform research

The [[https://www.omi.me/][Omi reference]] describes capture, transcripts, summaries, tasks and searchable
memory. It is a product reference, not evidence of Zara capability.
[[https://developer.android.com/develop/background-work/services/fgs/service-types][Android microphone foreground service rules]] require visible user-authorized microphone
ownership; background/boot start restrictions still apply.
[[https://developer.android.com/reference/android/speech/SpeechRecognizer][SpeechRecognizer]] is not intended for continuous recognition; on-device availability
and language/model readiness must be checked.
[[https://developer.android.com/training/wearables/data/client-types][Wear Data Layer ChannelClient]] supplies connection-oriented transport without persistence.
[[https://developer.android.com/reference/androidx/work/PeriodicWorkRequest][WorkManager periodic jobs]] have a 15-minute minimum and can be delayed.
[[https://docs.python.org/3.15/using/android.html][CPython Android embedding]] and [[https://chaquo.com/chaquopy/doc/current/android.html][Chaquopy]] are packaging research paths, not
implemented Zara Android runtimes. Preserve Zara's existing Trealla dialect/authority.
