#+title: Org workspace, Org-roam, and symbolic memory
#+startup: overview

* What Zara does
Zara treats Org files as canonical user-owned source. The desktop Copilot can
render those files with larger outline headings while keeping the literal Org
stars visible. Org-roam IDs, aliases, tags, links, backlinks, parent/child
relationships, and project properties are indexed into a rebuildable graph.

The index is a projection only. Zara does not replace your Org files or make a
private database authoritative.

* Configuration precedence
Org browser configuration is resolved in this order:

1. Zara browser defaults.
2. =[org]= values in =config.toml=.
3. runtime overrides set by the canonical Prolog runtime.
4. trusted local =$XDG_CONFIG_HOME/zarathushtra/org_browser.py=.

The later layer wins for scalar settings. Prolog roots/help sources replace the
TOML lists when at least one Prolog entry exists. Python may then add, clear, or
replace those lists. Python browser customization is executable trusted local
code and is loaded only when =[hooks].enabled = true= and
=[org].python_config_enabled = true=.

Zara never crawls the whole filesystem implicitly. Roots are explicit.

#+begin_src toml
[org]
enabled = true
roots = ["~/org", "~/Documents/roam"]
default_project = "zara"
memory_sync = true
base_font_pt = 13.0
heading_scales = [1.45, 1.30, 1.18, 1.10, 1.04]
max_files = 2000
max_file_bytes = 2000000
search_limit = 200
show_backlinks = true
show_properties = true
recent_chat_limit = 5
help_sources = [
  "README.org",
  "docs/README.org",
  "wiki/android.org",
  "wiki/customization.org",
  "wiki/agent-mode.org",
]
python_config_enabled = true

[hooks]
enabled = true
allow_override = false
#+end_src

Desktop Copilot's expanded view exposes an =Org= button. Search covers title,
aliases, tags, and body text. Selecting a node renders its source file and can
show backlinks. =id:= links can jump to the indexed node.

* Prolog configuration
The Prolog API lives in =kb_config=. This is executable configuration: trusted
=hooks.pl= can calculate values, branch on local facts, and call arbitrary
permitted Prolog before applying browser settings.

#+begin_src prolog
configure_org_browser :-
    kb_config:set_org_browser_setting(base_font_pt, 14.0),
    kb_config:set_org_browser_setting(search_limit, 100),
    kb_config:set_org_browser_setting(show_backlinks, true),
    kb_config:set_org_browser_setting(show_properties, false),
    kb_config:set_org_browser_setting(default_project, "zara"),
    kb_config:clear_org_browser_roots,
    kb_config:add_org_browser_root("~/org"),
    kb_config:add_org_browser_root("~/Documents/roam"),
    kb_config:set_org_browser_heading_scale(1, 1.65),
    kb_config:set_org_browser_heading_scale(2, 1.40),
    kb_config:clear_org_browser_help_sources,
    kb_config:add_org_browser_help_source("README.org"),
    kb_config:add_org_browser_help_source("wiki").

:- initialization(configure_org_browser).
#+end_src

Available mutation predicates include:

- =set_org_browser_setting/2= and =clear_org_browser_setting/1=
- =add_org_browser_root/1= and =clear_org_browser_roots/0=
- =set_org_browser_heading_scale/2= and =clear_org_browser_heading_scales/0=
- =add_org_browser_help_source/1= and =clear_org_browser_help_sources/0=
- =reset_org_browser_config/0=

The =org_browser_setting/2=, =org_browser_root/1=,
=org_browser_heading_scale/2=, and =org_browser_help_source/1= predicates expose
runtime overrides. =org_browser_effective_setting/2= and the corresponding
effective heading/help predicates include defaults for normal Prolog queries.

* Python configuration and browser hooks
Trusted =org_browser.py= receives a facade in =configure(org)=. It can override
settings and attach ordered transforms without editing Zara core.

#+begin_src python
def configure(org):
    org.set("base_font_pt", 15.0)
    org.set("search_limit", 120)
    org.set("show_backlinks", True)
    org.add_root("~/notes/current-project")
    org.heading_scale(1, 1.7)
    org.heading_scale(2, 1.4)
    org.help_source("wiki/org-workspace.org")

    org.filter_node(
        lambda node, config: "private" not in node.tags,
        priority=10,
    )
    org.sort_nodes(
        lambda nodes, config: sorted(
            nodes,
            key=lambda node: (node.project or "", node.title.casefold()),
        ),
        priority=20,
    )
    org.render_document(
        lambda document, rendered, config: rendered,
        priority=30,
    )
    org.filter_help_sources(
        lambda paths, config: [p for p in paths if not p.startswith("rage/")],
    )
    org.memory_tags(
        lambda node, tags, config: [*tags, "browser-projected"],
    )
    org.memory_text(
        lambda node, text, config: text,
    )
#+end_src

Python hook stages are =filter_node=, =sort_nodes=, =render_document=,
=filter_help_sources=, =memory_tags=, and =memory_text=. They are deterministic,
priority ordered, inspectable, and operate on projections only. They never make
the derived index or memory store canonical.

* Prolog lifecycle hooks
The existing =zara_hooks= registry exposes browser lifecycle stages. A trusted
=hooks.pl= can observe or react to:

- =org_browser_before_index=
- =org_browser_after_index=
- =org_browser_before_render=
- =org_browser_after_render=
- =org_browser_node_selected=
- =org_browser_help_open=
- =org_browser_before_memory_sync=
- =org_browser_after_memory_sync=
- =memory_sync=, the existing generic memory-sync stage

Example:

#+begin_src prolog
my_memory_sync(sync(Created, Updated, Deleted, Unchanged)) :-
    format('org memory: +~w ~w changed -~w (~w unchanged)~n',
           [Created, Updated, Deleted, Unchanged]).

install_my_memory_hook :-
    zara_hooks:register_hook(org_browser_after_memory_sync,
                             user_org_memory,
                             20,
                             my_memory_sync,
                             _).
#+end_src

* Doom-style rendering
The renderer does not replace =*=, =**=, and deeper heading prefixes with
bullets. It keeps the Org source visible and changes font size/weight by outline
level. Heading scale and base font are configurable. Unknown constructs stay
visible. Source blocks are rendered as source; rendering and indexing never
execute them.

* Org-roam memory hook
With =[org].memory_sync = true=, nodes carrying an Org =ID= are projected into
Zara long-term memory. Each memory keeps provenance in =source= using the form
=org-roam:<ID>= and tags including:

- =org-roam=
- =symbolic-memory=
- the node's Org tags
- =project:<name>= when =PROJECT= / =CATEGORY= or =default_project= supplies a project

Python =filter_node=, =memory_tags=, and =memory_text= hooks apply to this
projection. Prolog receives the browser memory-sync lifecycle events. Changing a
node replaces its projection. Deleting a node removes the projection. The Org
file remains canonical in every case.

The current Org projection is queryable through
=org_roam_memory:org_memory/5= and =org_roam_memory:org_project_context/3=.
The text is inert data. Embedded Org Prolog/source blocks are not consulted or
executed during indexing.

* Context sent to the model
When Org memory is active, Zara builds bounded context in four explicit groups:

1. Symbolic memories
2. Project context
3. Ordinary facts
4. Recent chat summaries

This separation is presentation/context policy; all rows still obey the existing
principal-scoped =MemoryManager= ownership rules. =recent_chat_limit= controls
the final group independently of semantic-memory =top_k=.

* Help sources
Desktop Help uses the same configured Org renderer and reads only repository
sources selected by =help_sources= plus the Python =filter_help_sources= hook.
Relative =file:= links remain constrained inside the repository root.

Android packages repository Org files at build time under =assets/help/= and
uses the shared literal-star Org renderer. This prevents a second handwritten
mobile help corpus from drifting away from the repo docs.

* Android notes / Org-roam
Full Android filesystem/workspace mutation remains owned by the separately
permissioned Zara Notes capability app tracked in =lost-rob0t/zara-plugins#807=.
The base Zara APK owns the shared renderer and help projection but does not
silently gain broad note-tree authority. Zara Notes uses SAF grants and keeps
user files canonical.
